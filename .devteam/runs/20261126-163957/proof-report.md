## Assumptions

Decided on the builder's behalf (change any that are wrong):

- Validation: an empty, whitespace-only or Windows-invalid name is refused with a message and nothing is created or changed.
- States: while a file operation runs the explorer shows a busy state; on failure it shows a clear message and reloads the true state; on success it refreshes the affected folder level or levels.
- States: creating a file or folder leaves it in the tree and does not open it in the editor; dropping an item onto the folder it is already in changes nothing.
- Scope: the engine and tdk 'up' action keeps starting every terminal; only the window's Start all / Stop all action and F5 honour the executable flag in this revision.
- Scope: the explorer's create, rename, move and delete operations extend the explorer's existing backend commands and the editor's existing store; no separate backend module is added.

## Out of scope

- Permanent deletion: delete always uses the Recycle Bin and refuses rather than deletes for good.
- Adding a separate backend module for the explorer's file operations: they extend the explorer's existing backend commands and the editor's existing store.
- The engine and tdk 'up' action: it keeps its current behaviour and still starts every terminal; only the window's Start all / Stop all action and F5 skip non-executable terminals. This is because changing engine.rs, which carries pre-existing failing tests, is outside this revision.
- Putting the editor inside the app view as a tab or split pane.
- Adding a keyboard shortcut for refresh or moving refresh off its buttons and palette entry.
- Changing what Start all / Stop all itself does beyond skipping non-executable terminals.
- Moving the command palette into a side pane.
- Changing Ctrl+O or the editor's existing file-picker behaviour.
- Choosing the explorer root by hand or adding an 'Open folder...' palette entry (excluded by earlier revisions).
- Rebuilding the explorer listing, the root rules, the theme-finder fit or the side panes already shipped in revisions 1 and 2.

### Analyst: requirements

This is revision 3 of 3 of the Tinkerdeck tidier editor feature (R9 to R12), built on the explorer browsing, root rules, F5 start/stop, theme-finder fit and side-pane work already committed. ### Architect: design

Revision 3 extends what revisions 1 and 2 already shipped; nothing is re-scaffolded. Per the settled decision, R9 does NOT add a separate backend module: the four file operations live as new plain functions in the existing explorer core (src-tauri/src/features/explorer/mod.rs) and their thin #[tauri::command] shells join the existing explorer commands (src-tauri/src/features/explorer/commands.rs). Rename and move call one additive Store::repath_prefix (src-tauri/src/editor.rs) so every open tab at or under the old path follows the new path and the derived tab groups recompute; the command returns those repaths so the window updates at once. Delete calls Store::close_prefix so a deleted file's or folder's tabs close, dirty tabs landing in the editor bin; the one delete confirmation names the item, says a folder's contents go with it, and folds in the unsaved-changes warning.
