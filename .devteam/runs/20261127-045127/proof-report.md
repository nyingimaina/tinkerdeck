### Architect: design

R1-R5 are a window-only change confined to the apps feature. The sidebar owns its own active tab as plain useState (never src/App.tsx, as revision 3 required), so clicking a rail icon just sets that tab and calls the onTogglePane callback the sidebar already receives. A fixed Projects | Files strip sits at the top of the expanded pane, built on the already-installed jattac.libs.web.zest-tabs (USR-001) through a thin SidebarTabs adapter that adds only the Enter/Space activation and the role=tabpanel wiring the library lacks; the library already gives role=tablist/role=tab, aria-selected, roving tabindex, ArrowLeft/Right selection and a focus ring. The existing Home row and app/terminal rows move verbatim into a memoised SidebarProjects child, and both panels stay mounted after first use, toggled with the hidden attribute. A tab switch is therefore O(1): it flips two hidden flags and the pill, never reconciles the 500-row Projects list and never re-reads a folder. The Files panel is mounted lazily on first use so opening on Projects costs no explorer listing. The explorer ReactNode/ExplorerPanel and root.ts are untouched, and every selection handler is left alone so nothing switches the tab by itself. No Rust command, src/api call, capability, CSP change, npm/crate dependency, version bump or localStorage key is added; the Files header name, roll-up dot, remembered tab and Ctrl+Shift+E are revision 2 and are not built here.
